# advanced/

**You do not need any of this to start.** The `SKILL.md` in the root is the whole product.

These are the elaborations one person added over a month, each because the simple version
was already working and something specific was missing. They are here as reference — for
the technique inside them, not to be installed.

| | What it adds | Add it when |
|---|---|---|
| `daily-digest/` | The full original, ~1,800 lines. Every source, every research lane, every rule learned the hard way. | You want to see how far this goes. Read it, don't run it. |
| `digest-checkin/` | A 5pm pass: how the day actually went, and whether the morning's claims survived. | The morning digest states things that turn out wrong by lunchtime. |
| `digest-feedback/` | Reads your replies and edits the skill file itself, then commits. | You keep giving the same feedback twice. |
| `telegram-remote/` | Any message becomes a real request, not just digest feedback. | You'd rather text the agent than open it. |
| `weekly-review/` | Sunday: trends rather than events, and an audit of what quietly got dropped. | Your action list stays the same length forever and you can't tell why. |
| `radish-daily/` | The same reporting aimed at a whole team instead of one person. | You want to share the output with people who aren't you. |
| `sync-skills/` | Mirrors the skill files into Notion. | You want to read them somewhere other than GitHub. |

**The one worth adding first is `digest-feedback/`.** Being able to reply "stop doing that"
and have the instructions actually change is what stops the whole thing drifting.

**A caveat on the self-improving loop:** it needs something always-on to watch for your
replies. That's easy on a machine that stays awake and awkward from a purely cloud agent.
Start without it.
